# D Animais — A importância dos grandes felinos

Projeto acadêmico de desenvolvimento web com conteúdo educativo sobre a importância dos grandes felinos e seu papel no equilíbrio dos ecossistemas. A página apresenta informações sobre tigres, onças-pintadas e leões.

## Funcionalidades

- Menu de navegação responsivo.
- Carrossel de imagens.
- Cards informativos sobre tigre, onça-pintada e leão.
- Badges com características dos animais.
- Janelas modais com informações adicionais.
- Accordion com especificações dos grandes felinos.
- Aviso educativo sobre ameaças à conservação das espécies.

## Tecnologias utilizadas

- HTML5
- CSS do Bootstrap 5
- JavaScript do Bootstrap (bundle)
- Font Awesome para ícones

## Como executar

O projeto é estático e não precisa de instalação de dependências.

1. Baixe ou clone este repositório:

   ```bash
   git clone https://github.com/ericneres/d-animais-grandes-felinos.git
   ```

2. Entre na pasta do projeto.
3. Abra o arquivo `index.html` em um navegador moderno.

Também é possível abrir o `index.html` diretamente no computador. Mantenha as pastas `css`, `js`, `img` e `fontawesome` nos mesmos caminhos para que os estilos, scripts, imagens e ícones sejam carregados corretamente.
